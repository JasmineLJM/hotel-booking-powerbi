# Data notice

`raw/hotel_bookings.csv` is the hotel booking demand dataset by Antonio, de Almeida & Nunes (2019),
*Data in Brief* 22, 41-49, [doi:10.1016/j.dib.2018.11.126](https://doi.org/10.1016/j.dib.2018.11.126).
This copy was taken from the course materials of the Udemy course *Python for Machine Learning & Data
Science Masterclass* (Pierian Data). Synthetic personal-data columns added in that copy (name, e-mail,
phone, card) were removed.

`model/` contains tables derived from it by `etl/build_model.py`.

The data is provided for **non-commercial, educational and portfolio use only** and is not covered by
the repository's MIT licence (which applies to the code).
