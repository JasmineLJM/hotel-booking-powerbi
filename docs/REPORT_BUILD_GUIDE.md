# Report build guide

The finished report ships in this repository as a Power BI Project (`Hotel_Booking_Analysis.pbip`),
generated by `tools/generate_pbip.py`. This guide documents the same design as manual steps, for
anyone who wants to rebuild it by hand in Power BI Desktop (free, Windows) from the CSVs in `data/model/`.

## 1. Load the data

1. **Home > Get data > Text/CSV** and load every file in `data/model/` (one at a time, or
   use **Get data > Folder** and expand). Keep the table names identical to the file names
   (`fact_bookings`, `dim_date`, ...).
2. In **Power Query**, check the column types:
   - `fact_bookings`: `booking_date`, `arrival_date`, `status_date` = **Date**;
     `adr`, `booking_value` = **Fixed decimal number**; `agent_id`, `company_id` = **Whole number**.
   - `dim_date[date]` = **Date**.
3. **Close & Apply**.

## 2. Model

1. **Model view**: create the relationships listed in [DATA_DICTIONARY.md](DATA_DICTIONARY.md).
   Power BI may auto-detect some of them; delete any it created between the wrong columns.
   - `fact_bookings[arrival_date]` -> `dim_date[date]`: active.
   - `fact_bookings[booking_date]` and `[status_date]` -> `dim_date[date]`: set **inactive**.
2. Select `dim_date` > **Table tools > Mark as date table** > column `date`.
3. Sort columns:
   - `dim_date[month_name]` and `[month_short]` -> sort by `month_number`
   - `dim_date[year_month]` -> sort by `year_month_sort`
   - `dim_date[day_of_week]` -> sort by `day_of_week_number`
   - `fact_bookings[lead_time_bucket]` -> sort by `lead_time_bucket_order`
4. Hide the foreign-key columns in `fact_bookings` (`hotel`, `country_code`, ...) so report
   users pick fields from the dimensions instead. Hide the `*_order` / `*_sort` columns.
5. **Home > Enter data**, create an empty table named `_Measures`, then add every measure in
   [`../powerbi/measures.dax`](../powerbi/measures.dax). Put them in the display folders noted in
   the file. Delete the placeholder column so `_Measures` moves to the top of the field list.
6. Formats: currency measures `€#,0`; `ADR` `€#,0.00`; rates `0.0%`.

## 3. Theme

**View > Themes > Browse for themes** and pick [`../powerbi/theme.json`](../powerbi/theme.json).

## 4. Pages

Every page has the same header: title on the left, `Report Subtitle` measure in a card under it,
and slicers on the right for **Hotel** (`dim_hotel[hotel]`) and **Year** (`dim_date[year]`).
Sync the slicers across pages (**View > Sync slicers**).

### Page 1 - Executive Overview

| Visual | Fields |
| --- | --- |
| 5 KPI cards | `Total Bookings`, `Room Revenue`, `ADR`, `Cancellation Rate`, `Avg Length of Stay (nights)` |
| Line chart: monthly revenue | X `dim_date[year_month]`, Y `Room Revenue` and `Room Revenue Rolling 3M`, legend none |
| Clustered column: revenue by hotel and year | X `dim_date[year]`, Y `Room Revenue`, legend `dim_hotel[hotel]` |
| Card pair: YoY | `Room Revenue YoY %` with subtitle "Trailing comparable months" |
| Donut: bookings by market segment | Legend `dim_market_segment[market_segment]`, values `Total Bookings` |

### Page 2 - Cancellations

| Visual | Fields |
| --- | --- |
| KPI cards | `Cancellation Rate`, `Canceled Bookings`, `Lost Revenue (Cancellations)`, `No-Show Rate` |
| Column: rate by lead time | X `fact_bookings[lead_time_bucket]`, Y `Cancellation Rate` |
| Bar: rate by market segment | Y `dim_market_segment[market_segment]`, X `Cancellation Rate`, sorted descending |
| Bar: rate by deposit type | Y `dim_deposit_type[deposit_type]`, X `Cancellation Rate` |
| Column: rate by special requests | X `fact_bookings[total_special_requests]`, Y `Cancellation Rate` |
| Line: cancellations by cancel date | X `dim_date[year_month]`, Y `Cancellations by Cancel Date` |

Add a constant line on the lead-time and segment charts at the value of
`Cancellation Rate (Hotel Baseline)` (Analytics pane > Constant line > fx).

### Page 3 - Guests & Markets

| Visual | Fields |
| --- | --- |
| Filled map | Location `dim_country[country_name]`, tooltip `Total Bookings`, `Cancellation Rate` |
| Bar: top 10 countries | `dim_country[country_name]`, `Total Bookings` (Top N filter = 10) |
| Clustered bar: domestic vs international | `dim_country[is_domestic]` (rename values in a calculated column or use groups), `Cancellation Rate` |
| Matrix: customer type | Rows `dim_customer_type[customer_type]`; values `Total Bookings`, `Cancellation Rate`, `ADR`, `Avg Length of Stay (nights)` |
| KPI cards | `Repeat Guest %`, `Avg Guests per Booking`, `Room Change Rate` |
| Column: meal plan | X `dim_meal[meal_plan]`, Y `Total Bookings` |

### Page 4 - Seasonality & Pricing

| Visual | Fields |
| --- | --- |
| Matrix heatmap: ADR | Rows `dim_date[month_short]`, columns `dim_hotel[hotel]`, values `ADR` with background color scale |
| Line: ADR by month | X `dim_date[month_short]`, Y `ADR`, legend `dim_hotel[hotel]` |
| Column: arrivals by weekday | X `dim_date[day_of_week]`, Y `Total Bookings` |
| Line: booking pace | X `dim_date[year_month]`, Y `Bookings by Booking Date` and `Total Bookings` (by arrival) |
| Scatter: segment economics | Details `dim_market_segment[market_segment]`, X `Cancellation Rate`, Y `ADR`, size `Total Bookings` |

### Optional extras (good to mention in interviews)

- **Drill-through page** "Booking Detail" with a table of `fact_bookings` rows, drill-through on market segment and country.
- **Tooltip page** for the map showing ADR and lead time for the hovered country.
- **Bookmarks** to switch the revenue chart between revenue and room nights.
- **Field parameter** (Modeling > New parameter > Fields) to let users choose the breakdown dimension on one chart.

## 6. Export for GitHub

1. Save the report (as `.pbip`, or **File > Save as** a `.pbix` if you want a single file).
2. Take one screenshot per page (**File > Export > Export to PDF** also works) and save them as
   `docs/screenshots/01_overview.png`, `02_cancellations.png`, `03_guests_markets.png`,
   `04_seasonality_pricing.png`. The README already links to these names.
3. Tip: set number formats or display units explicitly (as the generator does). Auto units such as
   "K"/"M" and the matrix "Total" label follow the Power BI UI language, not the report.
